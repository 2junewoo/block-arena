# 블록 아레나

블록형 3D FPS (웹 + 멀티). 개인전, 방 코드로 입장, 한 방 최대 5명. PC·모바일 크로스 플레이.

이 게임만의 규칙:

- **망령 시스템**: 라운드 중에 죽으면 망령이 되어 벽을 통과해 날아다니며, 8초마다 블록을 놓거나 지울 수 있다. 내 블록이 막은 피해는 점수판에 "망령 방어"로 남고, 다음 자기장 위치에 투표할 수 있다.
- **라운드 규칙 카드**: 라운드에서 가장 먼저 죽은 사람이 다음 라운드 규칙을 3장 중 하나로 고른다 (저중력, 헤드샷만, 블록 탄, 안개, 거인, 거꾸로 자기장).
- **캐릭터**: 캐릭터마다 고유 무기 1개 + 고유 스킬(E) 1개. 입장 화면에서 고르고, 대기실·준비 시간에 C로 바꾼다 (캐릭터 구성은 친구의 [project_fps](https://github.com/sol0404/project_fps)에서 가져옴)
	- 치이카와(밸런스): 체력 120, 풀베기 카빈(단발), 용기 충전 = 체력 50 회복 (12초)
	- 하치와레(돌격): 체력 100, 노래 라이플(연사), 대시 = 이동 방향으로 돌진 (6초)
	- 우사기(기동): 체력 90, 우라 SMG(연사), 우라! = 높이 뛰기 (7초)
- 그 밖에: 라운드제(준비 10초 → 전투, 먼저 5승), 줄어드는 자기장, 부서지는 블록, 서버 판정(되감기 명중 판정, 스킬도 서버가 판정)

Claude Code와 함께 만든 과정은 `docs/`에 있다 (대화·도구 호출만 남기고 개인 정보는 지운 공개본).

- [`docs/session-2026-10-30.jsonl`](docs/session-2026-10-30.jsonl): 기획부터 망령·규칙 카드·모바일까지
- [`docs/session-2026-11-06.jsonl`](docs/session-2026-11-06.jsonl): 친구 게임 project_fps와 비교·합치기 (캐릭터 시스템, 치이카와 모델)

## 실행

```
npm install
npm start          # http://localhost:3000
```

같은 와이파이의 친구는 `http://<내 IP>:3000`, Tailscale이면 Tailscale IP로 접속.

## 캐릭터 모델 (선택)

`client/models/chiikawa_and_friends.glb`가 있으면 캐릭터가 치이카와 모델로 보이고, 없으면 블록 아바타로 보인다. 모델은 "chiikawa and friends" by Nini (CC BY-NC 4.0, 비상업적 이용만)라서 저장소에는 넣지 않는다 (`.gitignore`). [project_fps](https://github.com/sol0404/project_fps)의 `client/models/`에서 가져오면 된다.

## 테스트

`DEV=1 npm start`로 띄우면 테스트용 순간이동(`{t:'tp'}`) 메시지를 받는다. 평소엔 꺼 둔다.

## 구조

- `shared/map.js` 블록 맵 (서버·클라이언트가 같은 함수로 생성)
- `shared/characters.js` 캐릭터 (체력·속도·무기·스킬)
- `shared/sim.js` 이동·무기·스킬 (서버 판정 + 클라이언트 예측이 같은 코드 사용)
- `shared/ray.js` 사격 광선 검사 (블록, 머리·몸통 판정 상자)
- `shared/zone.js` 자기장 일정
- `server/index.js` 정적 파일 + WebSocket, 60틱 판정, 초당 20번 상태 전송
- `client/models.js` 캐릭터 모델 불러오기, `client/world.js` 장면·맵·아바타, `client/fx.js` 총 모델·탄 궤적·소리, `client/minimap.js` 미니맵, `client/touch.js` 터치 조작, `client/main.js` 네트워크·입력·HUD·캐릭터 선택
